# adsoft_files

# English

Examples of infrastructure as code on ADSoft (Aécio and Déo Software).

Content:

- [app_python](app_python/README.md): Python app instrumented with the Prometheus client library.
- [app_nodejs](app_nodejs/README.md): contact list app with Node.js, Express, MongoDB and AngularJS.
- [app_crud_api](app_crud_api/README.md): CRUD REST API with Node.js, Express and MongoDB.
- [prometheus](prometheus/install_prometheus-operator_k8s/README.md): installation of Prometheus Operator (kube-prometheus-stack) in Kubernetes clusters.
- [helm_apps](helm_apps/README.md): Argo CD, Zabbix and HashiCorp Vault in Kubernetes.
- [aws_services](aws_services/README.md): Terragrunt/Terraform code to create resources in AWS (VPC, EKS, ALB, ...).
- [gcp_services](gcp_services/live/resources/nonprod/nonprod-vpc-host/README.md): Terragrunt/Terraform code to create resources in GCP (VPC, GKE, Cloud SQL, ...).
- [CLAUDE.md](CLAUDE.md): guidance to work on this repository with Claude Code (structure, conventions and how to test).
